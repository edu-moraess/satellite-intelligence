# SATELLITE INTELLIGENCE

**Earth Observation & Deep Geospatial Intelligence**

A clean, modular Streamlit platform for exploring any location on Earth, retrieving Sentinel-2 imagery via STAC, computing spectral indices, running U-Net semantic segmentation, and generating a concise geospatial intelligence report.

> **Principle: Less is more.**  
> Few features. Excellent execution. Professional interface. Deep Machine Learning.

**Current version: V1**

## Capabilities

- Global Location Catalog
- Sentinel-2 L2A via STAC
- COG raster analysis
- NDVI / NDWI / NDBI
- U-Net architecture (PyTorch)
- Change Detection baseline
- Geospatial visualization

## Current limitation

Deep Learning inference is disabled until a real trained U-Net checkpoint is provided in `models/checkpoints/`.

See full README structure in the repository after complete publish.
